# تدبّر — Tadabbur ✨

منصة لمشاركة الحِكَم والاقتباسات والتدبّرات المُلهمة، مبنية بإطار العمل **Laravel** و **Tailwind CSS**.

## ✨ المميزات
- **مشاركة التدبّرات والاقتباسات**: إضافة، تعديل، وحذف الاقتباسات الخاصة بك.
- **المحفوظات (Bookmarks)**: حفظ الاقتباسات المفضلة للرجوع إليها في تبويب وصفحة خاصة لكل مستخدم.
- **نظام حسابات متكامل**: تسجيل حساب جديد (`/signup`) وتسجيل الدخول (`/login`) مع تشفير كلمات المرور.
- **واجهة عربية/إنجليزية أصيلة**: تصميم مستوحى من العمارة الإسلامية باللون الزمردي والذهبي وخط أميري (Amiri).

## 🚀 التشغيل المحلي (Local Setup)

```bash
composer setup
php artisan serve
```

## 🌐 النشر على الاستضافات السحابية (Deployment)

المشروع مهيأ بالكامل للنشر المباشر من GitHub (يتضمن الأصول المجمّعة `public/build` وملف `Procfile` والإنشاء التلقائي لقاعدة بيانات SQLite):

1. اربط المستودع بمنصة الاستضافة (مثل **Railway** أو **Render** أو **Laravel Cloud**).
2. أضف متغير البيئة `APP_KEY` (يمكنك توليده بالأمر `php artisan key:generate --show`).
3. سيتم تشغيل الترحيلات (`php artisan migrate --force`) وتشغيل السيرفر تلقائياً.
